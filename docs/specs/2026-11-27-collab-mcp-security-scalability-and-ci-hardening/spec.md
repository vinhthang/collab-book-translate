## Problem and source intent

A full codebase and OpenViking architecture review of `collab-book-translate` (`HEAD` `71310f4`, `MCP v4.7.0`) surfaced critical security, reliability, scalability, and documentation drift issues:
1. **Unbounded Pre-Auth Body Buffering & Perimeter Gaps (`P0`/`P1`)**: `RequestContextMiddleware` drains `POST /mcp` and `/messages*` chunks without enforcing the `10 MiB` cap before buffering; `_parse_json_body` accepts `text/plain` POSTs without `Content-Type: application/json` or `Origin`/`Sec-Fetch-Site` CSRF validation on `/admin*`; `resolve_auth` fails open when `TRUST_ADMIN_SSO_HEADER=true` and `COLLAB_ADMIN_EMAILS` is empty; `_extract_client_ip` trusts `CF-Connecting-IP`/`X-Forwarded-For` from untrusted peer IPs; `SlidingWindowRateLimiter` never evicts expired buckets; failed auth attempts are unthrottled; and 3-word `AGENT_KEY` wordlists use 128 words/slot (~21 bits) while leaking both `w1` and `w3` in `key_hint`.
2. **Event-Loop Blocking, DB `N+1` Blobs, & Split-Brain Acceptance (`P1`)**: `v4.7.0` added synchronous DB presence calls directly inside `async def RequestContextMiddleware.__call__`, regressing the `2026-11-20` event-loop offload invariant (`2026-11-20-collab-mcp-async-offload-and-bg-seed.md`); `CollabStore._exec()` opens a fresh PostgreSQL connection per query and defines zero secondary indexes; `list_books()` loads full `source_text` and loops `1 + 2*N` queries; `rounds_history` duplicates `translation_xml`; `_finalize_accepted_chapter()` commits DB `accepted` state before `git push` succeeds; and `_upload_github_release()` ignores upload errors / existing assets.
3. **Runtime UI Crash, CI/CD Gaps, & Modularity/Doc Drift (`P1`/`P2`)**: `.js-retry-seed` in `admin_ui.py` throws `ReferenceError: hold is not defined`; `.github/workflows/ci-cd.yml` runs zero `pytest` checks before deploying and hardcodes `vinhthang/collab-mcp` during digest lookup; `Dockerfile` ignores `uv.lock` and runs as `root`; `scripts/extractors/__init__.py` eagerly imports `pymupdf`; circular imports exist between `collab_seed <-> collab_worker` and `db <-> auth`; `epub_compiler.py:699` emits `SyntaxWarning`; `agent_heartbeat` calls a no-op `_check_read_rate`; and `/llms.txt`, MCP prompts, `README.md`, `plugin.json`, `CONTRIBUTING.md`, and `agents/collab_translator.md` still describe `v3.0.0` `ANONYMOUS` writes.

Authorizing user intent (2026-11-27, prompt + `/ask_question` choices `A1`–`A3`):
- **Prompt**: *"review this project"* -> *"now fix these findings"*
- **A1**: Fix all `P0` + `P1` issues and targeted `P2` cleanups (lazy extractors, circular imports, `agent_heartbeat` rate limit, docs/`/llms.txt`/OpenViking sync), deferring splitting `CollabMcpService`.
- **A2**: Keep 3-word `AGENT_KEY` format and existing keys valid, expand wordlists (>= 256 words/slot), mask hint to `w1-***`, and add failed-auth IP rate limiting.
- **A3**: Add linked delta spec package (`v4.8.0` / `v0.9.1`) and implement on a feature branch (no push to `main`).

## Requirements

### REQ-082: Pre-Auth Body Streaming Cap, `/admin` Browser CSRF Gate, Fail-Closed SSO, & Trusted-Proxy IP Extraction

- Changes: [2026-11-23-collab-mcp-reader-threads-and-invite-lockdown/REQ-070](../2026-11-23-collab-mcp-reader-threads-and-invite-lockdown/spec.md#req-070-invite-only-registration--writes-private-owner-permission-manuscript-block-concise-reviews--2000-chars--test-artifact-purge)
- Source intent: Resolved `A1` (*"Fix all P0 + P1 issues"* — P0 OOM buffering, `/admin` CSRF, empty `COLLAB_ADMIN_EMAILS`, and IP header spoofing).
- Previous contract: `RequestContextMiddleware` and `_parse_json_body` buffered unlimited HTTP request bodies in memory; non-empty JSON routes accepted `text/plain` without `Content-Type: application/json` or `Origin`/`Sec-Fetch-Site` validation; `resolve_auth` granted `ADMIN` to any `X-Auth-Request-Email` when `cfg.admin_emails` was empty; `_extract_client_ip` unconditionally trusted `CF-Connecting-IP` and `X-Forwarded-For`.
- Statement: `RequestContextMiddleware` and `_parse_json_body` SHALL enforce a strict `10 MiB` (`10 * 1024 * 1024` bytes) cumulative body cap while streaming request chunks, aborting immediately with HTTP `413` before buffering further chunks. Non-empty request bodies parsed by `_parse_json_body` SHALL require a JSON media type (`application/json` or `*+json`), returning HTTP `415` otherwise. Mutating `/admin*` HTTP requests (`POST`, `PUT`, `DELETE`, `PATCH`) SHALL reject `Sec-Fetch-Site: cross-site` or mismatched `Origin` headers with HTTP `403`. `resolve_auth` SHALL fail closed on `/admin*` Forward-Auth SSO whenever `cfg.admin_emails` is empty (`ANONYMOUS` unless `sso_email in cfg.admin_emails`), and `_extract_client_ip` SHALL honor `CF-Connecting-IP` / `X-Forwarded-For` ONLY when `cfg.trust_proxy_headers` is `True` or socket `client_ip` is in `cfg.trusted_proxy_ips`.
- AC-082-1 — Success: Requests <= `10 MiB` with `Content-Type: application/json` and same-origin (or non-browser empty `Origin`) succeed; valid `X-Auth-Request-Email` matching configured `admin_emails` resolves `ADMIN`; trusted proxy `127.0.0.1` forwards client IP cleanly.
- AC-082-2 — Boundary/failure: Streaming `> 10 MiB` to `POST /mcp` or `/api/v1/*` returns `413` early without reading remaining body chunks; `Content-Type: text/plain` non-empty POST returns `415`; cross-origin `Origin` or `Sec-Fetch-Site: cross-site` on `/admin/*` POST returns `403`; `trust_admin_sso_header=True` with empty `admin_emails` remains `ANONYMOUS` (`403` on `/admin`); untrusted socket IP cannot spoof rate-limit IP via `CF-Connecting-IP` or `X-Forwarded-For`.

### REQ-083: Expanded 3-Word `AGENT_KEY` Entropy, Prefix-Only `key_hint`, Bounded Limiter, Failed-Auth Throttle, & Heartbeat Rate Limit

- Changes: [2026-11-23-collab-mcp-reader-threads-and-invite-lockdown/REQ-070](../2026-11-23-collab-mcp-reader-threads-and-invite-lockdown/spec.md#req-070-invite-only-registration--writes-private-owner-permission-manuscript-block-concise-reviews--2000-chars--test-artifact-purge), [2026-11-27-collab-mcp-agent-live-presence-and-readability/REQ-079](../2026-11-27-collab-mcp-agent-live-presence-and-readability/spec.md#req-079-hybrid-live-mcp-presence-tracker-protocol-ping--explicit-agent_heartbeat)
- Source intent: Resolved `A1` + `A2` (*"Keep 3-word format & existing keys valid, expand wordlists + mask hint to w1-*** + add failed-auth IP rate limiting"*, plus `agent_heartbeat` rate-limit fix).
- Previous contract: Wordlists held 128 words per slot (~21 bits), `mint_agent_key` returned `w1-***-w3`, `SlidingWindowRateLimiter` never pruned expired keys, invalid Bearer/`agent_key`/`admin_token` attempts had zero rate limiting, and `agent_heartbeat` called `_check_read_rate` (which only checked `ANONYMOUS`).
- Statement: `scripts/mcp_server/keys.py` SHALL define `>= 256` unique lowercase alphabetic words in each of `_ADJECTIVES`, `_NOUNS`, and `_PLACES`, preserve existing SHA-256 key verification, and mint `key_hint` as `f"{w1}-***"`. `SlidingWindowRateLimiter.check` SHALL prune expired timestamps and remove empty buckets so idle entries do not accumulate unboundedly. `resolve_auth` SHALL charge failed credential attempts (`admin_token`, `Bearer`, `agent_key`) against `f"auth_fail:{ip_hash}"` using `cfg.auth_fail_rpm` (`AUTH_FAIL_RPM`, default `20`), raising `RateLimitError` (`429`) when exceeded. `CollabMcpService.agent_heartbeat` SHALL enforce `f"heartbeat:{ctx.actor_id}"` against `cfg.agent_heartbeat_rpm` (`AGENT_HEARTBEAT_RPM`, default `60`, returning `429` when exceeded) without consuming `agent_write_rpm`.
- AC-083-1 — Success: Newly minted keys match `^[a-z]+-[a-z]+-[a-z]+$` with `key_hint == f"{w1}-***"`, legacy `w1-***-w3` and `cbt_ak_*` rows keep authenticating, expired limiter buckets are evicted automatically, and `agent_heartbeat` allows up to `agent_heartbeat_rpm` requests/minute independently of write quota.
- AC-083-2 — Boundary/failure: Exceeding `auth_fail_rpm` invalid token checks from an IP returns `429`; exceeding `agent_heartbeat_rpm` returns `429`.
