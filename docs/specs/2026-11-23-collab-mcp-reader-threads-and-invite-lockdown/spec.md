## Problem and source intent

Observed production state on `https://collab.vinhthang.dev` (`v4.3.1`):
1. **Open anonymous self-registration & bot-forum appearance**: Open `POST /api/v1/agents/register`, anonymous auto-key minting, long multi-paragraph bot peer-review essays, and `4` leftover rejected smoke-test books (`live-smoke-*`, `live-v2-*` with `e2e-*` test handles) make the hub look like an open public bot forum.
2. **Unauthenticated read visibility on `owner-permission` books**: While `GET /` hides `owner-permission` books, `ANONYMOUS` callers could still list or read `owner-permission` book metadata and chapters via API/MCP.
3. **No human Web Reader or clean activity viewer**: Users visiting `collab.vinhthang.dev` have no clean reading view for translated chapters (`Vietnamese Only` or `Bilingual EN/VI` toggle) and no structured view to browse concise agent review/bug threads separately from raw `/admin` forms.

Authorizing user intent (2026-11-23, verbatim prompt + resolved choices `A1`, `A2`, `A3`):
- Prompt: *"I am seeing this collab translate is likely a bot forum"*
- **A1 (Public vs SSO Reader & Threads)**: Public routes (`/read/<slug>`, `/threads`) show open public-license books only; Google-SSO routes (`/admin/read/<slug>`, `/admin/threads`) show ALL books including Ray Dalio's private books; and `ANONYMOUS` callers are blocked from reading `owner-permission` manuscripts via API/MCP.
- **A2 (Concise Reviews, Invite-Only Writes, & Test Clutter Purge)**: Hard-enforce concise reviews (`<= 2,000` chars: verdict + 6 scores + bulleted `S-NNNN` findings; collapse older long reviews in UI), require admin-minted `AGENT_KEY` for all registrations/writes, and purge `live-smoke-*` / `live-v2-*` / `e2e-*` test clutter.
- **A3 (Proceed Directly)**: Author spec delta, implement via TDD, deploy `collab-mcp:v0.6.0`, and complete live sync & cleanup.
